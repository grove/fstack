# Documentation

Choose the documentation type that matches what you need. This organization follows
[Diátaxis](https://diataxis.fr/).

- [Use fstack with an agent](how-to/use-with-an-agent.md): native skill discovery or explicit text loading.
- [Compose methods](how-to/compose-methods.md): join results without creating hidden dependencies.
- [Add or improve a skill](how-to/author-a-skill.md): write an independent method and a useful evaluation case.
- [Evaluate skills](how-to/evaluate-skills.md): assess behavior without confusing structure with effectiveness.
